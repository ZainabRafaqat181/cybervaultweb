# 🔐 Cyber Vault - Secure File Encryption & Decryption System

**Live Demo:** https://cybervaultweb.vercel.app

Cyber Vault is a secure web-based application that protects your sensitive data using military-grade Fernet (AES-128) encryption. It allows users to encrypt and decrypt text instantly with a secure key.

### ✨ Features
- Secure AES Encryption with Fernet
- Instant Decryption with Secret Key
- 100% Web Based - No Installation Needed
- Clean, Modern and Responsive UI
- Fast, Lightweight and Privacy Focused
- No data stored on server

### 🛠️ Tech Stack
- Backend: Python Flask
- Encryption: Cryptography Fernet (AES)
- Frontend: HTML, CSS, JavaScript
- Deployment: Vercel
- Version Control: GitHub

### 📁 Project Structure
cybervaultweb/
├── app.py
├── requirements.txt
├── vercel.json
└── templates/
    └── index.html

### 🚀 How To Use
1. Open website link
2. For Encryption: Enter your text and click Encrypt button
3. Copy the encrypted code
4. For Decryption: Paste encrypted code and click Decrypt button
5. Get your original text back
